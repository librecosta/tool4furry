# B21-D1 Regex Workbench

## 执行规则

- **匹配**在可编辑测试文本中标记完整匹配、捕获范围和零宽位置。捕获可以位于完整匹配之外。详情显示左闭右开的 UTF-16 区间，并区分空字符串和未参与匹配的捕获组。
- **替换**采用 ECMAScript 字符串替换语义。构建结果前逐段检查扩展大小。差异超出预算时，完整有效的替换结果仍可复制及下载。
- **提取**按匹配顺序输出完整匹配或者指定捕获组，支持去重。TXT 的未参与项与空字符串均用空字段表示。JSON 分别用 `null` 与 `""` 表示。CSV 使用 `status,value` 表头和 `absent`、`matched` 状态，记录使用 CRLF。
- **测试用例**每条独立编译 RegExp，支持匹配、不匹配、匹配数量及替换结果断言。超时、输入超限和非法预期值属于执行错误。

regexpp 4.12.3 按 ECMAScript 2025 语法解析表达式。引擎支持的 Flags 由浏览器探测。浏览器支持时，内部启用 `d` 读取精确索引。解释器无法生成结构时仍保留原生执行能力。结构图使用 React SVG 节点和文本，不注入用户提供的标记。依赖的 [完整 MIT 许可与来源](../../../src/tools/regex-tester/regexpp.NOTICE.txt) 随 Draft 开发产物提供。

## 资源边界

| 项目 | 边界 |
| --- | --- |
| 表达式、测试文本、替换表达式 | 分别为 16 Ki、2 Mi、64 Ki UTF-16 单元 |
| UTF-8 文件导入 | 8 MiB 字节预检，解码后 2 Mi UTF-16 单元 |
| 匹配记录 | 最多 10,000 条，并受累计 4 Mi 捕获数据与记录开销估算约束 |
| 匹配扫描 | 最多处理 100,000 条。提前终止时显示保留量或资源状态 |
| 替换与提取 | 最多 16 Mi UTF-16 单元。替换展开最多 200 万操作 |
| 只读结果预览 | 显示前 64 Ki UTF-16 单元，复制和下载使用完整有效结果 |
| 差异 | 原文与结果各 24 Ki UTF-16 单元、120 ms、1200 编辑距离 |
| AST 与结构图 | 4096 个节点、深度 64。结构图最多使用 180 个 AST 节点 |
| 测试用例 | 40 条。每个文本或预期值 128 Ki，累计 1 Mi UTF-16 单元 |
| 时间 | 实时防抖 240 ms，默认 Worker 时限 1500 ms，手动选择 1500/3000/5000 ms。测试用例累计运行检查 1000 ms |

Worker 时限包括启动和消息传递。取消及超时实际终止 Worker。任务按当前输入校验，旧结果禁止交付。匹配详情分页显示，未完成扫描的部分结果不能作为完整提取下载。
