# 浏览器本地图片处理契约

范围是已实现的图片工具正确性、安全、隐私和生命周期；具体预算与参数以 [limits.ts](../src/tools/image/limits.ts)、[presets.ts](../src/tools/image-converter/presets.ts)、编码适配器及对应测试为准，不在多份文档维护数值。

## 文件与真实输出

- 用户文件只在浏览器内读取、处理、预览与下载，不上传或持久保存。加载本站编码资源不等于上传图片。
- 扩展名/MIME 只是线索：真实容器、尺寸、帧数、方向、能力、资源预算和完整解码必须验证。不可信结构检查有界，异常偏移/长度/CRC/未知不可靠结构安全拒绝。
- 不静默替换输出格式，不自动缩小图片绕过预算，不把动画第一帧当作完整转换。不支持的高位深/HDR/特殊容器明确拒绝。
- EXIF/容器方向只应用一次；预览、实际显示尺寸、输出方向一致。无损重封装不能套用所有重编码结果方向必须为 1 的假设。
- PNG/WebP/AVIF 的透明度与 JPEG 背景合成遵守实际参数；不承诺无条件无损、文件必定更小、ICC/广色域或来源凭证保真。

## 默认隐私与受限保留

- 默认 `privacy-v1` 移除可识别的常见 EXIF/GPS、XMP、IPTC、文本注释等来源信息；必要且验证过的方向和色彩描述可保留，ICC 不等同 GPS。不能宣称清除所有私有数据、像素水印或隐写。
- Quick 同格式 PNG/JPEG/WebP 仅在确认无需清理时原字节直通；可安全清理时无损重封装。不能可靠清理则明确失败，允许用户主动 Advanced，不能静默回传隐私数据或自动有损重编码。
- AVIF 没有可靠的无损清理器，Quick 同格式也重新编码；不复制来源附加字段。所有输出执行符合实际策略的独立格式/元数据复检。
- Advanced `author-rights-v1` 仅支持 JPEG 来源到 JPEG/PNG/WebP 的已验证 Artist/Copyright 白名单，受限有界读取并写入新的最小结构；不复制完整 EXIF、GPS、设备、时间、缩略图或旧方向。不支持的组合明确禁用或逐项失败，不虚称保留成功。不能通过简单复制宣称 C2PA 签名有效。
- 正常编码/基础清理 → 受控白名单写回 → 按选定策略最终验证；不得跳过复检，也不能在最终复检时误删已批准的白名单。
- 元数据策略属于有效 Settings 和结果标记；切换策略使旧结果失效，Quick 始终恢复默认隐私。原始 File 不修改。

## 任务、交付与资源

Resize & Crop 单图编辑额外区分 Source（已验证且方向校正后的原图）、Crop（Source 整数像素矩形）和 Output（最终宽高/格式/质量/背景）。裁剪宽高统一最近整数取整，位置遵循稳定中心和 Source 边界约束；响应式只做坐标投影。未应用的输入字符串不写入处理状态；改变输出比例通过重构图匹配，不拉伸像素。导出从原图一次绘制裁剪与目标尺寸，再编码、默认隐私清理和完整输出复检；不得经中间有损文件二次编码。数值及联动细节以 [geometry](../src/tools/image-resize-crop/geometry.ts)、[render](../src/tools/image-resize-crop/render.ts) 和对应测试为准。

- 工具拥有批次、稳定任务 ID/序号、source/settings/request 版本与业务状态；只有当前已验证 ready 结果可以预览为有效输出、下载或进入 ZIP。删除、清空、换参数与跨批次晚到结果不能写回。
- 单通道 FIFO 不丢任务，单项失败不阻塞后续。原生不可硬取消操作在真实结束前继续占用通道；不能因 UI 取消提前启动另一重型操作。
- AVIF 编码按实际输出任务懒加载独立单线程 Worker/WASM，普通格式及 AVIF 输入不加载编码器；复用初始化，超时/取消真实终止 Worker，隔离晚到响应，随后可重建。资源预算、空闲/高水位回收不可无界放宽。
- 改文件名不编码；实际影响编码/隐私的设置进入 equality、预设/恢复和请求快照。能力重试不得覆盖用户主动选择的格式。
- 单项下载与 ZIP 共用有效结果资格；ZIP 快照在实际下载前再校验批次、任务顺序、结果版本和名称/参数。变化时丢弃，不能混入过期 Blob。打包逐项逐块、有界输出，最终 Blob 仍占浏览器内存，不宣称零内存。
- 工具级 `ImageResources` / URL owner 释放 Bitmap、Canvas、Object URL 和 Worker；替换/删除/卸载清理，仍由缩略图使用的原图 URL 不能随 Dialog 关闭提前撤销。公共 FileTaskList/预览外壳不持有 File/Blob、解码器或任务队列。

实现与验证入口见 [当前 Converter 说明](../docs/image-converter-implementation.md)，架构理由见 [ADR-0002](../docs/decisions/0002-browser-local-image-processing.md)。未测浏览器、真实移动设备和总内存范围按 L3 披露，不将桌面结果推广为全设备保证。
